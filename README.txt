SOLUTION MAKER SUPPLY CHAIN LTD — WEBSITE PACKAGE

1. Extract this ZIP file.
2. Open the folder and check index.html.
3. Replace YOUR-COMPANY-EMAIL@example.com in assets/site.js with the official company email.
4. Update verified phone number, registered office address and any company details in contact.html.
5. Upload ALL files and folders to your GitHub repository (not only index.html).
6. In GitHub: Settings → Pages → Deploy from branch → main → /(root) → Save.
7. Open the GitHub Pages URL after deployment.

Every main navigation item has its own HTML page:
- index.html
- about.html
- services.html
- ai-digital.html
- funding.html
- partners.html
- contact.html

Every service card also opens its own page inside /services:
- food.html, clothing.html, housing.html, education.html, healthcare.html, transport.html

Important:
- This is a static front-end website. The contact form opens the visitor's email app; it does not store submissions in a database.
- AI/digital services and funding are presented as proposed service areas, not as guaranteed active services.
- Add only accurate company claims, contact details, registration information and policies before public launch.
